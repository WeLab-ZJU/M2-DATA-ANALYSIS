To capture the manifold of neuronal activity in a low-dimensional space, we employed the recurrent switching linear dynamical systems (rSLDS) [1]. Code used to fit rSLDS is from the GitHub (https://github.com/lindermanlab/ssm). Firstly, we constructed a neural signal matrix which had dimensions m × n, where m represents the number of time points and n denotes the number of neurons. Then we excluded the first two minutes of the calcium signal to eliminate signal interference caused by the suspension device at the start of the experiment [2]. The key model parameters were configured as follows: the number of neural states K = 2, corresponding to the behavioral states of struggle and immobility; and the dimensionality of the continuous state D = 2 [3].

To assess whether the observed line attractor scores exceeded the level expected by chance, we generated surrogate datasets using independent phase randomization [4]. For each mouse, N = 1,000 surrogate time series were generated by independently randomizing the Fourier phases of each latent dimension. For each surrogate dataset, we refitted the state dynamics matrix and recomputed the line attractor score. The observed attractor scores were compared with the means of their corresponding surrogate distributions using a paired t-test across mice. A line attractor score significantly greater than its surrogate null indicates dominant-axis organization that cannot be explained by the marginal spectral properties of the individual latent dimensions.
