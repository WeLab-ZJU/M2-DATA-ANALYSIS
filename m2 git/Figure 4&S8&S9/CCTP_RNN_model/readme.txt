Cross-cohort transition-profile RNN model (CCTP-RNN)
We developed a recurrent neural network (RNN) model to recapitulate the responses of four distinct neuronal-types recorded in the tail suspension test (TST): Layer-2/3 excitatory neurons, and PV, SST, and VIP-expressing inhibitory neurons. First, we defined behavioral state transitions (both immobility-to-struggle and struggle-to-immobility) as onsets and extracted neural signals from time interval [-5s, 5s] seconds related to onset. Subsequently, these segments were then aligned by transition onset, and the average activity traces of each neuronal type across separate animal cohorts were matched in sequence to construct the training datasets.

The model consists of four independent LSTM subnetworks, each corresponding to one neuronal type. Interactions between subnetworks were directed cross-population connections, which are phenomenological model parameters and do not correspond to measured synaptic connectivity. Based on prior knowledge of connectivity patterns between excitatory and inhibitory neurons, we initialized all connections. The only constraint was that VIP neurons could receive unidirectional connections from excitatory neurons, without exerting a direct effect on excitatory neurons. During training, inputs were delivered to all four subnetworks in the time interval [ -4, -3.5] seconds relative to onset, and each subnetwork generated predicted activity. By comparing these predicted values with the actual recorded neural activity data, the mean squared error (MSE) is calculated as the loss function, and the network parameters (including connection weights) are updated through the backpropagation algorithm.
